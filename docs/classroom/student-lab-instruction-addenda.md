# Student Lab 2 instruction addenda

The frontend shows a versioned student-facing addendum for the exact scenario/course pairs `sc-hw-02`/`hw` and `sc-net-f26-02`/`net`. It appears above the evidence form in My Tickets and preserves the original client request.

Version 1 provides goal, equipment, ordered steps, safety, required evidence, completion criteria, and station reset. It does not import instructor notes, known faults, diagnostic answers, or rubric scores. Students still need instructor approval and physical signoff.

This is a frontend addendum, not a per-ticket snapshot. Deploying it makes the current addendum visible on matching existing tickets without rewriting their issued descriptions or evidence. No migration, reissuance, membership change, grading change, or deadline is required.

For later revisions, increment the visible version and publication date, document the changed instructions here, and retain the previous wording in Git history. If instructions materially change an issued assignment, obtain instructor approval before publication and explicitly explain the change to affected students. Do not silently rewrite original ticket descriptions or saved work.
